## 🛠️ Troubleshooting Common Issues

Even simple tools can sometimes behave unexpectedly. Here are a few common situations and what you can do:

- **A monitor is not showing up:** Make sure the monitor is connected and turned on. In Windows display settings, confirm that the screen is detected. Then reopen DisplayFusion so it can refresh the monitor list.
- **Taskbars are not appearing on all screens:** Check the taskbar settings in the application and make sure the option for multiple taskbars is enabled. Some Windows settings may also affect taskbar behavior.
- **Hotkeys are not working:** Another program might be using the same shortcut. Try changing the hotkey in the app’s settings to a combination that is not already in use.
- **Saved layouts are not restoring correctly:** Make sure the monitors are connected in the same arrangement as when you saved the layout. If you change cable connections or monitor positions, you may need to save a new layout.
- **The app feels slow:** Close unused programs and restart the application. If the issue continues, check for updates or restart your computer.

If you run into a problem that is not covered here, the application’s built-in help and the official DisplayFusion documentation are good places to look. The repository page may also have additional notes.
